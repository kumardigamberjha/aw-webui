# Coding Standards for ActivityWatch Dashboard Upgrades

You are an expert developer contributing to `aw-webui`. When writing or refactoring code for the dashboard layout, strictly adhere to these rules:

## 1. Zero Direct Database Interactivity
- Never import database drivers or storage modules into frontend files.
- All communications must happen through `aw-client-js` or browser `fetch()` requests pointing to the local server API (`/api/0/query`).

## 2. Server-Side Aggregation Only (Asynch Queries)
- Do not download thousands of raw window events into JavaScript loops.
- Write your calculations inside ActivityWatch's server-side query string language (Asynch queries) so the server returns clean, pre-calculated metric summaries.

## 3. Design System Integration
- Use the existing global styling layout ecosystem present inside `src/` (Bootstrap-Vue, native components, and existing theme variables) so any new dashboard elements match the current application perfectly.
